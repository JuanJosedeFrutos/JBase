# JBase

JBase es un sistema de gestión bibliotecaria para catalogación y búsqueda de bibliotecas personales.

## Descripción

Este proyecto nace a partir del deseo de crear una herramienta para la gestión de un bibilioteca personal. Tomando como referencia protocolos y procedimientos de sistemas de gestión bibliotacarios profesionales, se pretende llevar a un entorno mucho más reducido. 

Además, se quieren añadir funcionalidades de registro personal como pueden ser reseñas, comentarios o valoraciones.

## Funcionalidades

- **Catalogación:** Descripción, análisis y organización de datos de documentos para facilitar su identificación, localización y recuperación en una base de datos.
- **Búsqueda:** Búsqueda de elementos en el catálogo.
- **Localización:** Identificación del lugar en el que se encuentra un documento.
- **Valoración:** Calificación que se otorgan a las obras.
